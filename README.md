# BankMarketingCampaign
Bank Marketing Campaign 
# Problem Statement
Optimizing Direct Marketing Campaigns for Bank Term Deposits. The Dataset contains historical direct phone-marketing data collected by a Portuguese banking institution and contain various client characteristics, past marketing touchpoints, and macro-economic factors.
# Dataset Description
Below features describe the personal and financial characteristics of the customers.
	age (Numeric): The exact age of the client.
	job (Categorical): Type of industry/occupation. Includes: admin., blue-collar, entrepreneur, housemaid, management, retired, self-employed, services, student, technician, unemployed, unknown.
	marital (Categorical): Marital status of the customer. Includes: divorced (which covers both divorced and widowed), married, single, unknown.
	education (Categorical): Highest level of education completed. Includes: basic.4y, basic.6y, basic.9y, high.school, illiterate, professional.course, university.degree, unknown.
	housing (Categorical): Has an active housing/home loan? (no, yes, unknown).
	loan (Categorical)
